# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability on the HVX Music website
(hvxmusic.com), please report it responsibly:

- Email: info@hvxmusic.com
- Subject line: "Security Report - HVX Website"

Please include:

1. A description of the issue
2. Steps to reproduce it
3. The page or file affected

We will review all reports and respond as soon as possible.
Please do not disclose the issue publicly until we have had a
chance to address it.

## Scope

This policy covers the HVX Music website and its source code in
this repository. Third-party services (Netlify, GoDaddy, Google)
have their own security programs and should be contacted directly
for issues in their platforms.
